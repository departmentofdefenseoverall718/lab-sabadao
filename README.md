## 📋 What Is This?

lab-sabadao is a powerful yet easy-to-use program that helps you test and compare different AI models. Think of it as a quality control lab for artificial intelligence. Whether you're a curious beginner or a tech enthusiast, this tool lets you see how well different AI systems perform, how fast they respond, and how smart they are at various tasks.

This application is based on the `gbench` benchmarking suite, which is a professional-grade tool used by developers worldwide. But don't worry - we've made it simple enough for anyone to use.

## ✨ Main Features

- **🤖 AI Model Testing**: Test multiple AI models side by side
- **📊 Performance Reports**: See how fast and efficient each model is
- **🎯 Capability Assessment**: Understand what each AI model can and cannot do
- **📈 Visual Dashboards**: Easy-to-read charts and graphs of results
- **🌐 Web Interface**: Use it through your web browser
- **🔌 Works with Popular AI Systems**: Compatible with vLLM, SGLang, TGI, Ollama, and more
- **💾 Automatic Results Saving**: Your test results are stored automatically
